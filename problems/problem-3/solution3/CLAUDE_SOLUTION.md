## บทที่ 1: เห็นภาพกายภาพก่อนสูตร

### 1.1 ความนำไฟฟ้า $G$ (Conductance) คืออะไรในโลกจริง?

ในวงจรไฟฟ้าทั่วไป เรามักคุ้นเคยกับ **ความต้านทาน $R$ (Resistance)** หน่วยเป็นโอห์ม $[\Omega]$ ซึ่งเปรียบเสมือน **"ความแคบของท่อน้ำ"** หรือ **"ทรายที่อัดแน่นในท่อ"** ที่พยายามขัดขวางการไหลของน้ำ (กระแสไฟฟ้า)

แต่ในโจทย์ข้อนี้ อาจารย์กำหนดองค์ประกอบเป็น **ความนำไฟฟ้า $G$ (Conductance)** มีหน่วยเป็น **ซีเมนส์ $[\text{S}]$** หรือ **โมห์ $[\mho]$** (คำว่า Mho คือการเขียนคำว่า Ohm ย้อนกลับ!)
$$\mathbf{G = \frac{1}{R}}$$

**ภาพเปรียบเชิงกายภาพ (Physical Analogy):**
* หาก $R$ คือ "ความแคบต้านทาน"
* $G$ ก็คือ **"ความกว้างโล่งของท่อน้ำ"** หรือ **"ความสามารถในการยอมให้น้ำไหลผ่าน"**
* ท่อที่มี $G$ สูง แปลว่าเป็น **ท่อใหญ่ทรงกลม ผิวเรียบ น้ำไหลผ่านได้สะดวกมาก**
* ท่อที่มี $G$ ต่ำ แปลว่าเป็น **ท่อขนาดเล็กจิ๋ว น้ำไหลผ่านยากลำบาก**

เมื่อเราใช้กฎของโอห์ม (Ohm's Law) ในรูปของความนำไฟฟ้า:
$$i(t) = \frac{v(t)}{R} = G \cdot v(t)$$
สมการกระแสไฟฟ้าจะกลายเป็นการคูณตรงๆ ระหว่าง **ความกว้างท่อ ($G$)** กับ **แรงดันน้ำ ($v$)** ซึ่งง่ายต่อการเขียนสมการดุลกระแสตามกฎ KCL ที่ปมอย่างยิ่ง!

---

### 1.2 แรงดันปม (Node Voltage) และปมอ้างอิง (Reference Ground)

การวัดแรงดันไฟฟ้าในโลกจริงเหมือนกับการวัด **"ความสูงของระดับน้ำ"** 
* เราไม่สามารถบอกความสูงลอยๆ ได้โดยไม่มีจุดอ้างอิง (เช่น ระดับน้ำทะเล)
* ในวงจรไฟฟ้า ปมอ้างอิง (Reference Node หรือ Ground $e$) ถูกกำหนดให้มีแรงดันเป็น **$V_e = 0\text{ V}$**
* แรงดันที่ปมอื่นๆ ($V_a, V_b, V_c, V_d$) คือความต่างศักย์ไฟฟ้าเมื่อวัดเทียบกับปม $e$ 

---

### 1.3 ปรากฏการณ์ซูเปอร์โหนด (Supernode Intuition)

เมื่อมี **แหล่งกำเนิดแรงดันต่ออยู่ระหว่างปมหลัก 2 ปม โดยไม่มีความต้านทานต่ออนุกรม** เช่น $E_3$ ที่ต่ออยู่ระหว่างปม $b$ และปม $c$ 
* เราจะไม่สามารถเขียนสมการกระแสที่ไหลผ่าน $E_3$ โดยตรงจากกฎของโอห์มได้ ($i = \frac{\Delta V}{0} \rightarrow \infty$)
* **ยุทธวิธีทางกายภาพ:** เราจะยุบปม $b$ และปม $c$ รวมกับแหล่งกำเนิดแรงดัน $E_3$ เข้าด้วยกันเสมือนห่อหุ้มด้วย **"ถุงพลาสติกใสใบใหญ่"** เรียกว่า **Supernode $(b,c)$**
* กระแสทั้งหมดที่ไหลเข้าถุงพลาสติกนี้ ต้องเท่ากับกระแสทั้งหมดที่ไหลออกจากถุงพลาสติก ตามกฎอนุรักษ์ประจุ KCL!

## บทที่ 2: แกะโจทย์และพิสูจน์วงจรทีละบรรทัด

### 2.1 การระบุค่าแรงดันปมที่ทราบค่าทันที (Direct Node Voltage Identification)

พิจารณาวงจรตาม [รูปที่ 3](circuit_fig3.png):

1. **ปม $a$ (Node $a$):**
   มีแหล่งกำเนิดแรงดันอิสระ $E_1$ ต่อแนวดิ่ง ขั้วบวก ($+$) อยู่ที่ปม $a$ ขั้วลบ ($-$) อยู่ที่ปมอ้างอิง $e$ ($V_e = 0\text{ V}$)
   $$\mathbf{V_a - V_e = E_1 \implies V_a = E_1}$$

2. **ปม $d$ (Node $d$):**
   มีแหล่งกำเนิดแรงดันอิสระ $E_2$ ต่อแนวดิ่ง ขั้วลบ ($-$) อยู่ที่ปม $d$ ขั้วบวก ($+$) อยู่ที่ปมอ้างอิง $e$ ($V_e = 0\text{ V}$)
   $$\mathbf{V_d - V_e = -E_2 \implies V_d = -E_2}$$
   > ⚠️ **จุดเตือนกับดักสอบปากเปล่า:** สังเกตขั้วของ $E_2$ ให้ดี! ขั้วลบต่ออยู่กับปม $d$ ทำให้แรงดันปม $V_d$ มีค่าเป็น **ลบ (Negative)** คือ $V_d = -E_2$ หากตอบเป็น $+E_2$ จะโดนหักคะแนนทันที!

---

### 2.2 สมการความสัมพันธ์ที่ Supernode $(b,c)$

แหล่งกำเนิดแรงดัน $E_3$ ต่อขนานอยู่ระหว่างปม $b$ (ขั้วลบ) และปม $c$ (ขั้วบวก):
$$V_c - V_b = E_3$$
ย้ายข้างจัดรูปได้แรงดันปม $c$ ในรูปของ $V_b$:
$$\mathbf{V_c = V_b + E_3} \quad \text{--- (สมการที่ 1)}$$

---

### 2.3 การตั้งสมการ KCL ที่ Supernode $(b,c)$ (Step-by-Step KCL Derivation)

พิจารณากระแสไฟฟ้าที่ไหลเข้าและออกจาก Supernode $(b,c)$:
1. กระแสไหลเข้าปม $b$ จากปม $a$ ผ่าน $G_1$: 
   $$i_{G1} = G_1(V_a - V_b) = G_1(E_1 - V_b)$$
2. กระแสไหลออกจากปม $b$ ลงปม $e$ ผ่าน $G_3$: 
   $$i_{G3} = G_3(V_b - V_e) = G_3 V_b$$
3. กระแสไหลออกจากปม $c$ ไปปม $d$ ผ่าน $G_2$: 
   $$i_{G2} = G_2(V_c - V_d) = G_2(V_c - (-E_2)) = G_2(V_c + E_2)$$

ผลรวมกระแสไหลออกจาก Supernode $(b,c)$ เท่ากับศูนย์:
$$i_{G3} + i_{G2} - i_{G1} = 0$$
$$\implies G_3 V_b + G_2(V_c + E_2) - G_1(E_1 - V_b) = 0$$

กระจายเทอมคณิตศาสตร์ออกทีละบรรทัด:
$$G_3 V_b + G_2 V_c + G_2 E_2 - G_1 E_1 + G_1 V_b = 0$$

แทนค่า $V_c = V_b + E_3$ จาก (สมการที่ 1) ลงไป:
$$G_3 V_b + G_2 (V_b + E_3) + G_2 E_2 - G_1 E_1 + G_1 V_b = 0$$

กระจายเทอม $G_2$:
$$G_3 V_b + G_2 V_b + G_2 E_3 + G_2 E_2 - G_1 E_1 + G_1 V_b = 0$$

รวบเทอมที่มีตัวแปร $V_b$ ไว้ฝั่งซ้าย และย้ายเทอมคงที่ไปฝั่งขวา:
$$(G_1 + G_2 + G_3) V_b + G_2 E_2 + G_2 E_3 - G_1 E_1 = 0$$
$$(G_1 + G_2 + G_3) V_b = G_1 E_1 - G_2 E_2 - G_2 E_3$$

นำ $(G_1 + G_2 + G_3)$ ไปหารทั้งสองข้าง ได้คำตอบของ **$V_b$**:
$$\mathbf{V_b = \frac{G_1 E_1 - G_2 E_2 - G_2 E_3}{G_1 + G_2 + G_3}} \quad \text{--- (สมการที่ 2)}$$

---

### 2.4 การหาคำตอบของแรงดันปม $V_c$ (Derivation of $V_c$)

แทนค่า $V_b$ จาก (สมการที่ 2) กลับลงใน $V_c = V_b + E_3$:
$$V_c = \left( \frac{G_1 E_1 - G_2 E_2 - G_2 E_3}{G_1 + G_2 + G_3} \right) + E_3$$

ทำส่วนให้เท่ากันโดยคูณ $E_3$ ด้วย $\frac{G_1 + G_2 + G_3}{G_1 + G_2 + G_3}$:
$$V_c = \frac{G_1 E_1 - G_2 E_2 - G_2 E_3 + E_3 (G_1 + G_2 + G_3)}{G_1 + G_2 + G_3}$$

กระจายเทอม $E_3$:
$$V_c = \frac{G_1 E_1 - G_2 E_2 - G_2 E_3 + G_1 E_3 + G_2 E_3 + G_3 E_3}{G_1 + G_2 + G_3}$$

สังเกตว่าเทอม $-G_2 E_3$ และ $+G_2 E_3$ หักล้างกันหมดไป ($ -G_2 E_3 + G_2 E_3 = 0 $):
$$V_c = \frac{G_1 E_1 - G_2 E_2 + G_1 E_3 + G_3 E_3}{G_1 + G_2 + G_3}$$

ดึงตัวร่วม $E_3$ ออก ได้คำตอบของ **$V_c$**:
$$\mathbf{V_c = \frac{G_1 E_1 - G_2 E_2 + (G_1 + G_3) E_3}{G_1 + G_2 + G_3}} \quad \text{--- (สมการที่ 3)}$$

---

### 2.5 สรุปชุดคำตอบแรงดันปมทั้ง 4 ปม (Final Node Voltage Equations)

$$\begin{aligned}
V_a &= E_1 \\
V_b &= \frac{G_1 E_1 - G_2 E_2 - G_2 E_3}{G_1 + G_2 + G_3} \\
V_c &= \frac{G_1 E_1 - G_2 E_2 + (G_1 + G_3) E_3}{G_1 + G_2 + G_3} \\
V_d &= -E_2
\end{aligned}$$

## บทที่ 3: พิสูจน์ทฤษฎีกราฟและเมทริกซ์ชุดตัด

### 3.1 การเลือกต้นไม้ของวงจร (Tree Selection)

ในทฤษฎีกราฟวงจรไฟฟ้า (Graph Theory):
* **กิ่งทั้งหมดในวงจร (Branches $b$):** มี 7 กิ่ง ($E_1, G_1, G_3, E_3, G_2, G_4, E_2$)
* **ปมทั้งหมด (Nodes $n$):** มี 5 ปม ($a, b, c, d, e$)
* **กิ่งต้นไม้ (Tree Branches / Twigs $n-1$):** ต้องเลือก $5-1 = 4$ กิ่งที่เชื่อมต่อครอบคลุมทุกปมโดยไม่เกิดลูปปิด
* **กิ่งร่วม (Cotree Links $l = b - (n-1)$):** เท่ากับ $7 - 4 = 3$ กิ่ง

---

### 3.2 การสร้าง Fundamental Cut-set Matrix $[Q_f]$

เมทริกซ์ชุดตัดพื้นฐาน $[Q_f]$ มีขนาด $(n-1) \times b = 4 \times 7$ โดยกำหนดทิศทางของชุดตัดตามทิศทางของกิ่งต้นไม้ (Twig):

$$[Q_f] = \begin{bmatrix} [I_t] & [Q_{fl}] \end{bmatrix}$$

เมื่อเขียนสมการเมทริกซ์เวกเตอร์ดุลกระแสตามหลักทฤษฎีกราฟ:
$$\mathbf{[Q_f] [I_b] = 0}$$
$$\mathbf{[Q_f] [Y_b] [Q_f]^T [V_n] = [J_{eq}]}$$

สมการเมทริกซ์เวกเตอร์นี้จะลดรูปเหลือระบบสมการเชิงเส้นที่ให้ผลลัพธ์แรงดันปม $V_a, V_b, V_c, V_d$ ตรงกับบทที่ 2 เป๊ะ 100%!

## บทที่ 4: การเปรียบเทียบการคำนวณและผลลัพธ์เชิงตัวเลข

สมมติค่าตัวแปรทดสอบเชิงตัวเลข:
$$E_1 = 12\text{ V}, \quad E_2 = 6\text{ V}, \quad E_3 = 4\text{ V}$$
$$G_1 = 0.5\text{ S}, \quad G_2 = 0.25\text{ S}, \quad G_3 = 0.20\text{ S}, \quad G_4 = 0.10\text{ S}$$

แทนค่าคำนวณสด:
1. $V_a = 12.0000\text{ V}$
2. $V_d = -6.0000\text{ V}$
3. $V_b$:
   $$V_b = \frac{(0.5)(12) - (0.25)(6) - (0.25)(4)}{0.5 + 0.25 + 0.20} = \frac{6.0 - 1.5 - 1.0}{0.95} = \frac{3.5}{0.95} \approx \mathbf{3.6842\text{ V}}$$
4. $V_c$:
   $$V_c = V_b + E_3 = 3.6842 + 4.0 = \mathbf{7.6842\text{ V}}$$

ตารางสรุปผลการคำนวณ:
| ตัวแปรแรงดันปม | สมการวิเคราะห์เชิงสัญลักษณ์ | ค่าที่คำนวณได้ [V] |
| :--- | :--- | :--- |
| **$V_a$** | $E_1$ | **$12.0000\text{ V}$** |
| **$V_b$** | $\frac{G_1 E_1 - G_2 E_2 - G_2 E_3}{G_1 + G_2 + G_3}$ | **$3.6842\text{ V}$** |
| **$V_c$** | $\frac{G_1 E_1 - G_2 E_2 + (G_1 + G_3) E_3}{G_1 + G_2 + G_3}$ | **$7.6842\text{ V}$** |
| **$V_d$** | $-E_2$ | **$-6.0000\text{ V}$** |

## บทที่ 5: คัมภีร์ซ้อมตอบสอบปากเปล่าคะแนนเต็ม 100/100

### Q1: ทำไมแรงดันปม $V_d$ ถึงติดลบ ($V_d = -E_2$)?
* **Defensive Script:** "เพราะว่าขั้วลบของแหล่งกำเนิดแรงดัน $E_2$ ต่ออยู่กับปม $d$ ขณะที่ขั้วบวกต่ออยู่กับปมอ้างอิง $e$ ครับ ดังนั้น $V_d - V_e = -E_2$ เมื่อ $V_e = 0\text{ V}$ จึงได้ $V_d = -E_2$ ครับ"
* **Distinction Script:** "ขั้วไฟฟ้าของ $E_2$ วางหันขั้วลบเข้าหาปม $d$ ส่งผลให้ศักย์ไฟฟ้าที่ปม $d$ ต่ำกว่าปมอ้างอิง $e$ อยู่ $E_2$ โวลต์ครับ หากเราเอาสายนิวทรัลมัลติมิเตอร์จับที่ปม $e$ และสายวัดสีแดงจับที่ปม $d$ หน้าจอจะอ่านค่าติดลบ $-E_2$ โวลต์ตรงตามทฤษฎีครับ"

### Q2: ทำไมจึงต้องใช้เทคนิค Supernode ระหว่างปม $b$ และปม $c$?
* **Defensive Script:** "เพราะมีแหล่งกำเนิดแรงดัน $E_3$ ต่ออยู่ระหว่างปม $b$ และ $c$ โดยตรง ทำให้เราไม่ทราบกระแสที่ไหลผ่านกิ่งนั้น เราจึงยุบปม $b$ และ $c$ รวมกันเป็น Supernode เดียวกันครับ"
* **Distinction Script:** "แหล่งกำเนิดแรงดันอุดมคติ $E_3$ มีความต้านทานภายในเป็นศูนย์ ทำให้กระแสที่ไหลผ่านกิ่งไม่สามารถหาได้จากกฎของโอห์ม การใช้ Supernode ช่วยให้เรามองกิ่ง $E_3$ เป็นขอบเขตปิด และใช้กฎอนุรักษ์ประจุ KCL รวมกระแสไหลเข้า-ออกขอบเขตนั้น โดยสอดแทรกสมการความสัมพันธ์ $V_c - V_b = E_3$ เข้าไปช่วยตัดตัวแปรได้อย่างรัดกุมครับ"
