การวิเคราะห์แรงดันปม (Node Voltages), ซูเปอร์โหนด (Supernode) และการสร้าง Fundamental Cut-set Matrix $[Q_f]$

📝 โจทย์ต้นฉบับข้อที่ 3

"พิจารณาวงข่ายความนำไฟฟ้า $G_1, G_2, G_3$ และ $G_4$ ซึ่งมีแหล่งกำเนิดแรงดันอิสระ $E_1, E_2$ และ $E_3$ ดังรูปที่ 3 จงเขียนสมการชุดตัดในรูปแบบเมทริกซ์เวกเตอร์และหาค่าแรงดัน $V_a, V_b, V_c$ และ $V_d$ ที่ปม $a, b, c$ และ $d$ ตามลำดับ เมื่อเปรียบเทียบกับแรงดันที่ปม $e$ ต่อลงดินและมีค่าเท่ากับศูนย์"

📊 ตารางสรุปตัวแปรและอุปกรณ์ (Component Matrix)

ตัวแปรประเภท / ชนิดการต่อในวงจรผลต่อการคำนวณ
E1 [V]Independent Voltage Sourceปม a กับ กราวด์ eVa = E1
E2 [V]Independent Voltage Sourceขั้วลบที่ปม d, ขั้วบวกที่ eVd = -E2 (ขั้วลบที่ปม d)
E3 [V]Independent Voltage Sourceระหว่างปม b (-) และ c (+)Supernode: Vc - Vb = E3
G1, G2, G3, G4 [S]Conductances (1/R)กิ่งต่างๆ ในวงข่ายคำนวณกระแส i = G · ΔV

💧 กายภาพของความนำไฟฟ้า G (Conductance Intuition)

ในวงจรไฟฟ้าทั่วไป เราคุ้นเคยกับความต้านทาน $R$ ($\Omega$) ซึ่งเปรียบเสมือน "ทรายอัดแน่นในท่อน้ำ" ที่คอยขัดขวางน้ำ

แต่ ความนำไฟฟ้า $G = \frac{1}{R}$ ($S$ หรือ $\mho$) เปรียบเสมือน "ความกว้างโล่งของท่อน้ำ" ยิ่งค่า $G$ สูง แปลว่าท่อใหญ่ น้ำไหลสะดวกมาก!

เมื่อใช้กฎของโอห์มในรูป $G$: i = G · v การคำนวณดุลกระแสที่ปมจะกลายเป็นการคูณตรงๆ ที่สะดวกและรวดเร็วมากครับ

📐 ขั้นตอนการพิสูจน์หาแรงดันปม (Step-by-Step Proof)

1. แรงดันปมทราบค่า: Va = E1 และ Vd = -E2

2. สมการ Supernode (b, c): Vc = Vb + E3

3. ตั้งสมการ KCL ที่ Supernode (b, c):

G1(Vb - E1) + G3·Vb + G2(Vc - (-E2)) = 0
G1·Vb - G1·E1 + G3·Vb + G2(Vb + E3 + E2) = 0
(G1 + G2 + G3)·Vb = G1·E1 - G2·E2 - G2·E3
Vb = (G1·E1 - G2·E2 - G2·E3) / (G1 + G2 + G3)

4. คำนวณ Vc:

Vc = Vb + E3 = (G1·E1 - G2·E2 + (G1 + G3)·E3) / (G1 + G2 + G3)

🕸️ ทฤษฎีกราฟ & เมทริกซ์ชุดตัด (Cut-set Matrix)

การวิเคราะห์วงจรด้วยทฤษฎีกราฟ เลือกต้นไม้ (Tree) มี 4 กิ่ง และกิ่งร่วม (Cotree Links) 3 กิ่ง

สมการเมทริกซ์ชุดตัดพื้นฐาน (Fundamental Cut-set Matrix $[Q_f]$):

[Qf] · [Ib] = 0
[Qf] · [Yb] · [Qf]^T · [Vn] = [Jeq]

🎓 คัมภีร์ซ้อมตอบสอบปากเปล่า (100/100 Oral Defense)

Q1: ทำไมแรงดันปม Vd ถึงมีค่าติดลบ -E2? ▼

Defensive Script ขั้วลบของแหล่งกำเนิด E2 ต่ออยู่กับปม d ครับ เมื่อวัดเทียบกับกราวด์ e (0V) จึงได้ Vd = -E2 ครับ

Distinction Script ขั้วไฟฟ้าของ E2 วางหันขั้วลบเข้าหาปม d ทำให้ศักย์ไฟฟ้าต่ำกว่ากราวด์อยู่ E2 โวลต์ หากเอานิวทรัลมัลติมิเตอร์จับที่กราวด์ e และสายวัดสีแดงจับที่ปม d หน้าจอจะอ่านค่าได้ -E2 โวลต์เป๊ะครับ

Q2: ทำไมจึงต้องใช้ Supernode ระหว่างปม b และ c? ▼

Defensive Script เพราะมีแหล่งกำเนิดแรงดัน E3 ต่ออยู่ระหว่างปม b และ c โดยไม่มีความต้านทานอนุกรม จึงไม่ทราบกระแสตรงๆ ต้องยุบรวมเป็น Supernode ครับ

Distinction Script แหล่งกำเนิดแรงดันอุดมคติ E3 มีความต้านทานภายในเป็นศูนย์ การใช้ Supernode ช่วยมองขอบเขตปิดล้อมปม b และ c เพื่อรวบสมการดุลกระแส KCL โดยสอดแทรกสมการ Vc - Vb = E3 เข้าไปแก้ระบบสมการได้อย่างรัดกุม 100% ครับ
