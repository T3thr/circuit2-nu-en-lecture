### 4. คำตอบสรุป (Quick Answer)

$$V_a = E_1 \qquad V_b = \frac{G_1E_1 - G_2E_2 - G_2E_3}{G_1+G_2+G_3} \qquad V_c = V_b + E_3 \qquad V_d = -E_2$$

**สามข้อสังเกตที่เป็นที่มาของคะแนนเต็ม:**
1. **$G_4$ ไม่โผล่ในคำตอบแรงดันเลย** เพราะ $V_d$ ถูกตรึงด้วยแหล่งจ่ายอุดมคติ $E_2$ ที่ต่อขนานกับ $G_4$
2. **รอยตัดพื้นฐานของกิ่ง $G_3$ = สมการ KCL ที่ supernode $(b,c)$ เป๊ะ** — supernode เป็นกรณีเฉพาะของทฤษฎีรอยตัด
3. **$V_d = -E_2$ ไม่ใช่ $+E_2$** เพราะขั้วลบของ $E_2$ อยู่ที่ปม $d$ (กับดักเครื่องหมายที่ทำให้คนตกเยอะที่สุด)
